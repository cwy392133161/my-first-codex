# 发音试听版检查记录

状态：**技术修正已完成，音频听感尚未验收通过**。开发代码保存在 `english-pronunciation-review` 分支。正式首页继续使用原发布版；新版本单独放在 `pronunciation-preview/`，用于试听核对。

## 已完成的修改

- 修正旧生成流程直接使用通用音素、与模型的双元音编码不同的问题。
- 改用官方 Misaki 0.9.4 英式读音处理，正确选择声线参数和浮点语速。
- 明确 close 的“关闭”读音、read/reads 的现在时读音、minute/minutes 的时间含义。
- 修正 34 张学习卡的朗读边界，将单词与例句分别听读。
- 全部重建为 398 段 MP3，覆盖 1,517 个朗读入口；不是新增题库数量。
- 使用新音频地址与脚本缓存版本。题目对象、题号、答案、浏览器记录键和备份格式保持不变。

## 程序检查

- 8 组英式音素/语义检查通过；全部 398 段没有未知或无法送入模型的音素。
- 398 段 MP3 全量解码、非静音和文件完整性检查通过。
- 8 组真实 MP3 浏览器流程、5 组家长试听流程通过。
- 40 组原生语音/文字降级流程、14 组备份恢复流程及原有 Node 检查通过。
- 基础练习、首次正确率、错题、刷新保存和页面布局检查通过。

这些检查证明生成输入、文件和软件流程符合预期，不能代替逐条听辨，也不证明音频发音全部准确。没有使用华为实体平板验收。本环境 Chromium 禁止 file:// 导航，因此只验证了经典脚本和相对本地文件结构，没有将 Windows 双击实测记为通过。

## 保留的声音质量疑虑

使用 PocketSphinx 5.0.4 自带美式模型进行不限制词典/语法的开放识别。新库 398 段中 34 段文字精确匹配；在可与旧库比较的 389 段中，旧 51 段匹配、新 34 段匹配。孤立英式短词、专名与合成声音会被这个模型误认，因此这些数字不是发音准确率。不过 hello、hi 和部分完整句子出现误认，不能忽略，也不能据此宣称已经解决所有发音问题。

另外比较 Emma 0.88、Emma 1.0、George 0.88、Isabella 0.88 四组共 44 段音频，没有获得稳定改善的识别证据。没有根据少数样本更换全库声线，也没有把识别结果包装成人工审听结果。

## 如何核对

打开在线试听页，先听 Hello、Hi，再搜索数字、颜色及其他词句，与老师或可靠词典的示范音对照。若仍然不准确，这版就应继续调整声音方案；正式网页暂不使用它。

试听页只播放本项目 MP3，不改用平板系统语音，不修改学习记录。试听版练习与正式页在同一个网站，使用同一浏览器记录；不需要清空数据。
