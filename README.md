# 一年级学习小乐园 🌱

供一年级孩子巩固基础知识的手机网页版。中文、大按钮、每屏一题，无登录、广告、倒计时或排名。题库为独立原创示例，不宣称与某教材完全同步。

## 如何打开

**最简单的方法：** 下载整个仓库并解压，双击 `index.html`，用 Chrome、Edge、Safari 或 Firefox 打开即可。不需要安装依赖，也不需要联网。

**推荐的方法：** 如果电脑已安装 Python，在仓库目录打开终端，输入：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Windows 上可改用 `py -m http.server 8000 --bind 0.0.0.0`。电脑浏览器打开 `http://localhost:8000`。手机和电脑连接同一个 Wi-Fi 时，手机打开 `http://电脑的局域网IP:8000`（例如 `http://192.168.1.12:8000`，请换成电脑实际 IP）。电脑防火墙需允许此服务；不要向公网开放。停止服务时按 Ctrl+C。

## 怎么练习

首页选择数学或语文 → 选择 5 题或 10 题 → 选择知识点。首次答错先给提示，点击“再试一次”，再次答错后显示答案和讲解。完成后显示温和鼓励和练习总结。

- 数学：10以内分与合、加减法、比较大小；20以内加减法为可选进阶。
- 语文：基础拼音辨认、常见字词搭配。
- 错题复习：随机选取错题；不足所选题数时按实际题数练习，不重复凑题。复习首次答对才移出错题本，提示后答对仍保留。
- 学习记录：按知识点显示练习次数和首次作答正确率。中途退出或刷新，已作答记录也保留；当前练习不自动续接。完整练习次数仅计完成的练习。

## 数据保存在什么地方

学习记录通过 `localStorage` 保存在当前浏览器，刷新后保留，**暂不支持跨设备同步**。不同浏览器、不同网址、不同端口各自保存记录；无痕窗口和清理浏览器数据可能删除记录。直接打开文件时，存储支持取决于浏览器，建议使用上面的本地服务方式。存储失败会在页面显示提醒。“清空学习记录”必须在确认窗口再次确认。

## 调整题库

- `data/questions.js`：独立题库和知识点定义，语文示例可直接调整；数学题由生成器计算答案。
- `app.js`：练习流程、错题和本地记录。
- `style.css`：手机及电脑样式。
- `index.html`：网页入口。

修改题库时请保持题目 ID 稳定；若修改旧题的含义，建议给它新 ID，避免与历史记录混淆。

## 开发检查

运行 `node tests/questions.test.js` 检查数学答案和题库。浏览器流程检查使用 Playwright 和 Chromium（开发检查工具，网页本身不需要它们）：

```sh
node tests/browser.test.js
```

浏览器检查覆盖错误后的重试、重复点击、错题重练、首次正确率、刷新保存、空记录、清空确认和手机布局。
