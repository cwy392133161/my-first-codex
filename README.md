# 一年级学习小乐园 🌱

供一年级孩子巩固基础知识的手机网页版。中文、大按钮、每屏一题，无登录、广告、倒计时或排名。语文练习为独立原创示例；英语按提供的 Power Up 词表图片整理，题目为原创练习，不宣称与整套教材完全同步。

## 如何打开

**最简单的方法：** 下载整个仓库并解压，双击 `index.html`，用 Chrome、Edge、Safari 或 Firefox 打开即可。不需要安装依赖，也不需要联网。

**推荐的方法：** 如果电脑已安装 Python，在仓库目录打开终端，输入：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Windows 上可改用 `py -m http.server 8000 --bind 0.0.0.0`。电脑浏览器打开 `http://localhost:8000`。手机和电脑连接同一个 Wi-Fi 时，手机打开 `http://电脑的局域网IP:8000`（例如 `http://192.168.1.12:8000`，请换成电脑实际 IP）。电脑防火墙需允许此服务；不要向公网开放。停止服务时按 Ctrl+C。

## 当前题库

语文共有 **120 道原创固定题**，按题干去重仍为 120 道：基础拼音辨认 60 道、常见字词搭配 60 道。拼音覆盖基础声母、韵母和声调；字词覆盖家庭、校园、身体、自然及日常生活。原有 24 道题的编号和内容保持不变，旧学习记录和备份仍可使用。

数学题由程序计算生成：10以内分与合45种、10以内加减法132种、比较大小121种、20以内加减法462种题目组合。20以内模块包含10以内题，以上是各模块组合数，不是固定题数量，也不是跨模块去重后的总数。

## 英语 · Power Up 词汇学习

首页点击 **“英语学习”**，按提供的词表图片选择 **Hello 或 Unit 1–4**。Hello 已按新增的学习目标、学习重点图片完善；Unit 1–4 目前覆盖词汇，不包含尚未提供的其他单元目标、教材音频或完整语法课程。

| 单元 | 内容 | 核心词 | 拓展词（*） | 全部词条 |
|---|---|---:|---:|---:|
| Hello | 颜色、1～10 | 21 | 0 | 21 |
| Unit 1 | 校园、学习用品与动作 | 28 | 6 | 34 |
| Unit 2 | 家庭、身体与感官 | 25 | 7 | 32 |
| Unit 3 | 动物、食物与描述 | 30 | 8 | 38 |
| Unit 4 | 食物与饮品 | 27 | 6 | 33 |
| 合计 | | **131** | **27** | **158** |

`father / dad` 等同义词组按一个词条计数；`orange`（橙色/橙子）和 `chicken`（鸡/鸡肉）在各自单元按不同词义学习。

1. **学单词**：看英文和中文，点击“听单词”，听完后自己跟读；可用“上一个 / 下一个”翻卡片。看词、听读不计入答题成绩。
2. **做练习**：选5题或10题，可选“综合练习”“选中文”（英→中）或“选英文”（中→英）。每词有两个方向的原创选择题，全部词条共316道练习组合；默认只练核心词，共262道。
3. **巩固**：首次答错进入错题本，按原有提示重试规则练习；家长可在学习记录查看各单元首次正确率。英语记录与旧语文、数学记录一起备份和恢复。

图片中带 `*` 的词是拓展词，默认不加入。勾选“包含拓展词”即可一起学习和练习。错题复习会保留所有已答错的题，不受此开关影响。

发音采用设备自带的英文语音，优先英式英语。不同设备的声音与可用性可能不同；无英文语音时会提示，仍可看词和完成练习。未提供麦克风录音或发音评分。网页无需登录，也不调用外部AI接口。

### Hello：按目标学习

进入 **英语学习 → Hello → 按学习目标学 Hello**，每个目标都可以先看示范、听读、自己开口，再选5题或10题练习。

| 学习目标 | 学习重点与练习 | 学习卡 | 目标题 |
|---|---|---:|---:|
| 打招呼 | Hello! / Hi!；问好、回应与听辨 | 3 | 12 |
| 数字 1–10 | one 到 ten；看数字、数星星、听数字 | 10 | 30 |
| 姓名与年龄 | What's your name? / How old are you?；问答、补句与听辨 | 4 | 30 |
| 认识颜色 | 11个颜色词；看色块、听颜色、自己说颜色 | 11 | 22 |
| 合计 | | **28** | **94** |

94道目标题是另外增加的稳定练习，其中29道听辨题；原有158个词条和316道双向词汇练习保留。题目按固定内容与模板整理，每题的编号及答案稳定；上表统计的是题目组合，不是运行或测试次数。人物名字卡包含图片中的8位朋友，用小图标辅助认识名字。年龄练习的原创示例会明确标注。

听辨题先点击“听题目”，没有英文发音支持或播放失败时会显示文字提示，也可主动点击“显示文字提示”。练习仍可完成。非听辨题在作答完成后提供答案听读，避免提前读出答案。

“我来说一说”由孩子自行练说，可以展开示范说法。点击“我试着说了”只给予鼓励，不记录发音成绩，也不采集真实姓名或年龄。学习卡浏览和听读不计入首次正确率；四个目标的选择题记录分别显示在学习记录里，参与错题复习和备份恢复。Unit 1–4 的词汇记录和原有语文、数学记录继续保留。

## 怎么练习

首页选择数学、语文或英语 → 选择 5 题或 10 题 → 选择知识点。首次答错先给提示，点击“再试一次”，再次答错后显示答案和讲解。完成后显示温和鼓励和练习总结。

- 数学：10以内分与合、加减法、比较大小；20以内加减法为可选进阶。
- 语文：基础拼音辨认、常见字词搭配。
- 英语：按 Hello / Unit 1–4 学词、听读和做原创选择题。
- 错题复习：随机选取错题；不足所选题数时按实际题数练习，不重复凑题。复习首次答对才移出错题本，提示后答对仍保留。
- 学习记录：按知识点显示练习次数和首次作答正确率。中途退出或刷新，已作答记录也保留；当前练习不自动续接。完整练习次数仅计完成的练习。

## 数据保存在什么地方

学习记录通过 `localStorage` 保存在当前浏览器，刷新后保留，**暂不支持跨设备同步**。不同浏览器、不同网址、不同端口各自保存记录；无痕窗口和清理浏览器数据可能删除记录。直接打开文件时，存储支持取决于浏览器，建议使用上面的本地服务方式。存储失败会在页面显示提醒。“清空学习记录”必须在确认窗口再次确认。

## 导出备份和导入恢复（新功能）

打开首页的 **“学习记录”**，向下找到 **“备份与恢复”**：

1. 点击 **“导出备份”**，浏览器会下载一个以“学习小乐园-学习记录”开头的 `.json` 文件。请到浏览器下载列表查看，保存在自己容易找到的位置。
2. 需要恢复时，点击 **“导入恢复”**，选择之前下载的 `.json` 文件。不要双击 JSON 文件，它是数据备份，不是程序。
3. 程序会显示备份包含的记录、新增记录数和合并后的错题数。确认后点击 **“确认导入”**；不想导入就点击 **“取消”**。

备份包含已作答题目的首次结果、完整练习统计和错题；未完成练习的已答记录也会保留，当前练习进度不会续接。**导入只合并、不清空现有记录；同一份备份多次导入，不会重复计数。** 已通过错题复习首次答对的题，不会因为导入同一段历史的较早备份而重新出现；不同设备记录按作答时间合并，请保持设备日期时间正确。

文件不正确、版本或题库不匹配、记录冲突或保存失败时会显示原因，原记录会保留。文件最大支持 5 MB。发生冲突时，请保留两份备份，不要手动改写数据强行导入。

导出本身不改变学习记录。换电脑、浏览器或网址时，可手动把备份文件带到新设备再导入，**这不等于自动同步**。更换程序文件夹可能改变浏览器记录位置，请先备份；清空记录前也建议导出备份。

## 调整题库

- `data/english.js`：图片中的英语词条、拓展标识和原创双向题库。
- `data/english-hello.js`：Hello 四个学习目标、学习卡、角色名字与原创目标题。
- `data/questions.js`：独立题库和知识点定义，语文示例可直接调整；数学题由生成器计算答案。
- `app.js`：练习流程、错题、本地记录及备份操作界面。
- `record-backup.js`：备份格式检查和记录合并。
- `style.css`：手机及电脑样式。
- `index.html`：网页入口。

修改题库时请保持题目 ID 稳定；若修改旧题的含义，建议给它新 ID，避免与历史记录混淆。

## 开发检查

在 Git 克隆的仓库中运行 `node tests/questions.test.js` 检查题库及与旧版本的兼容性（这项检查需要 Git 历史），运行 `node tests/record-backup.test.js` 检查备份协议和错题合并规则。浏览器流程检查使用 Playwright 和 Chromium（开发检查工具，网页本身不需要它们）：

```sh
node tests/english.test.js
node tests/english.browser.test.js
node tests/hello.test.js
node tests/hello.browser.test.js
node tests/browser.test.js
node tests/backup.browser.test.js
```

浏览器检查覆盖错误后的重试、重复点击、错题重练、首次正确率、刷新保存、空记录、清空确认和手机布局。

备份检查还覆盖真实下载文件、恢复与取消、重复导入、保留旧记录、无效/超大文件拒绝及保存失败保护。
